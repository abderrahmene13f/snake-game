# 🐍 Snake Game

A modern browser-based Snake Game built with **HTML, CSS, and JavaScript**.

Play the game directly in your browser!

## 🎮 Play Online

### [▶️ Play Snake Game](https://abderrahmene13f.github.io/snake-game/)

## ✨ Features

* Smooth snake movement
* Modern dark-themed interface
* Score tracking and best score
* Increasing difficulty
* Poison obstacles
* Keyboard and mobile controls
* Pause, restart, and game-over functionality
* Responsive design

## 🕹️ Controls

| Key   | Action         |
| ----- | -------------- |
| ↑ / W | Move Up        |
| ↓ / S | Move Down      |
| ← / A | Move Left      |
| → / D | Move Right     |
| Space | Pause / Resume |

Mobile users can use the on-screen direction buttons.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* HTML Canvas
* GitHub Pages

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/abderrahmene13f/snake-game.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
